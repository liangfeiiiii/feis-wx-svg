# 我给公众号做了套苹果风 SVG 动效工具

公众号排版这件事，做到最后往往陷入两个极端。

一端是纯白底黑字，读起来顺畅，但关键观点压不住视觉重心，滑过去就忘了。另一端是整篇做成动效长图，从头到尾全在动，文字既不能选中也不能复制，长文看下来眼睛很累。

我想要的是中间那条路。正文老老实实保持原生排版，只在真正需要停顿和强调的地方，放进一块克制、干净、自己会轻轻动起来的纯 SVG 卡片。

于是有了 feis-wx-svg。

[插入 SVG 模块 1：01-原生动效零负担.html]

它不靠视频，不靠 GIF，也不写一行 JavaScript。公众号后台在保存文章时非常严苛，凡是带脚本、滤镜、渐变或者元素 ID 的代码都会被直接抹掉，而且不会报错。

很多看似炫酷的网页动效，粘进公众号就只剩一团死图。

真正能稳定活下来的，是 SVG 原生的属性动画和形变动画。把所有会被清洗的标签提前清干净，只留最纯粹的几何形状、系统字体和苹果风格的缓动曲线，单个模块往往不到 10KB，打开文章那一刻就能满帧滑出来。

[插入 SVG 模块 2：02-公众号删什么留什么.html]

设计上我只守一条规矩，克制。

不需要花哨的色块堆砌，也不用廉价的弹窗感。白底配浅雾灰卡片、极细的 1px 边框、充足的留白，再加上从左到右缓缓拉开的线条和错峰浮现的 Bento 网格。所有动画在三秒左右安静定格，绝不抢正文的风头。

[插入 SVG 模块 3：03-为什么选图文混排路线.html]

为了平时发稿顺手，我还顺带做了一个配套的 Chrome 侧边栏插件。

以前做完 SVG 还要找第三方网页粘贴中转，来回切窗口很打断写作节奏。现在直接在公众号后台点开侧边栏，把生成好的模块包拖进去，插件会自动检查有没有触发微信禁忌、支持一键切换深浅底预览，光标停在哪，点一下就直接插进正文。

[插入 SVG 模块 4：04-三步完成发稿闭环.html]
